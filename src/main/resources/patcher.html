Where to get a decrypted copy, and using the result

On a 3DS with custom firmware, GodMode9 can build a decrypted CIA of a title installed on it, and dump a game card as a decrypted .3ds. The copy has to be decrypted: this page cannot read an encrypted one.

Install a patched CIA in place of the original: with FBI on a 3DS with Luma3DS, or in Citra (or Azahar) with File → Install CIA. Play a patched .3ds in Citra, or have GodMode9 build a CIA from it to install on a 3DS. A patched game needs no Luma3DS game patching: if you used the patch's luma folder before, delete its romfs folder.

If the DLC was installed before and the game still shows its old text, the game is showing its own copy of that text, kept in its Ext Save Data. Back up the game's save data and Ext Save Data with Checkpoint, then delete the game's Ext Save Data with FBI (Ext Save Data → the game → Delete). The game makes it again from the patched DLC. Its save data is not touched; if the game kept anything else in its Ext Save Data and you miss it, restore that with Checkpoint.

Keep your decrypted copy: installing it puts the original back.
